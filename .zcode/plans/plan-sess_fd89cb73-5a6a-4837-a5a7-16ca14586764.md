# 全面搬运 Python→Flutter 缺失功能与修 bug 实施计划

## 背景
对照 Python 原版 (`D:\env\cfnb`) 与 Flutter 新版 (`D:\env\cfnb_app`) 全部源码后确认:配置数据模型(95 字段)已 1:1 转移,但**功能层**存在正确性 bug 与多处缺失。本计划按用户确认方向「全部补齐」执行。CFData 扫描阶段(依赖 Windows 外部 exe)按用户要求暂不实现,仅文档标注。

---

## A. 正确性 Bug 修复(最高优先级)

### A1. DNS 过滤环节完全失效 🔴
- **现状**:`run_pipeline.dart:120` 直接 `dnsUpdate(finalNodes, ...)`,只用 `_toContent` 做格式转换,**从未调用 `filterDnsCandidates`**。导致 IPv6 落地过滤、DNS 国家黑名单、IP 风险等级、端口(443)过滤全部不生效。
- **修法**:在 `RunPipeline.run()` 阶段6,先收集可用性检测的栈信息 `Map<String,String>`(由 `checkNodeAvailability` 返回的 ipv4/ipv6 推断,经 `buildStackMap`),用 `filterDnsCandidates(speedResults.map((r)=>(r.node,r.speedMbps)).toList(), stackMap, config)` 筛选,再把结果喂给 `updateCloudflareDns`。需要让 `filterAvailable` 同时返回栈信息。
- **文件**:`lib/core/pipeline/run_pipeline.dart`、`lib/core/availability/availability_prober.dart`(`filterAvailable` 改为返回 `(List<String>, Map<String,String>)`)、`lib/features/run/run_state.dart`(`dnsUpdate` 闭包改写)。

### A2. 延迟单位 ×1000 bug 🔴
- **现状**:`latency_prober.dart` 返回的是**毫秒**(`Stopwatch.elapsedMilliseconds`),但 `ip_writer.dart:25` 又 `latencyMap[node]! * 1000`;`final_selector.dart` 的 `qualityLatencyRef=400` 与 `computeQuality` 也按毫秒算但参考值偏大。
- **修法**:统一为**毫秒**语义。`ip_writer.dart` 去掉 `*1000`;`final_selector.dart` 的 `qualityLatencyRef` 调整为合理毫秒参考值(如 400ms);DNS 更新打印处 `latencyMap[node]` 直接用毫秒。
- **文件**:`lib/core/output/ip_writer.dart`、`lib/core/selection/final_selector.dart`、`lib/core/dns/cf_dns.dart`(若有引用)。

### A3. 漏斗截取缺失(BANDWIDTH_CANDIDATES) 🟡
- **现状**:`run_pipeline.dart:94` 把全部可用节点喂给测速;Python 先按延迟排序截前 `BANDWIDTH_CANDIDATES` 名。
- **修法**:阶段5测速前,按 `latencyMap` 排序取前 `min(bandwidthCandidates, available.length)`。
- **文件**:`lib/core/pipeline/run_pipeline.dart`。

### A4. 前置过滤黑名单开关用错字段 🟡
- **现状**:`selectFinalNodes` 用 `filterBlockedCountriesEnabled`(DNS 黑名单总开关)做前置国家过滤;Python 前置过滤用独立的 `PRE_FILTER_BLOCKED_ENABLED`+`PRE_FILTER_BLOCKED_COUNTRIES`,DNS 过滤才用 `FILTER_BLOCKED_COUNTRIES_ENABLED`+`BLOCKED_COUNTRIES`。
- **修法**:前置过滤分两层——① `selectFinalNodes` 改用 `preFilterBlockedEnabled`+`preFilterBlockedCountries`;② DNS 过滤由 A1 的 `filterDnsCandidates` 负责(用 `filterBlockedCountriesEnabled`+`blockedCountries`)。
- **文件**:`lib/core/selection/final_selector.dart`。

## B. 缺失功能补齐

### B1. ip.txt 历史副本(对应 Python `_save_history`)🟡
- **现状**:无历史保存。
- **修法**:新建 `lib/core/output/history_store.dart`(或扩展现有 `latency/history_store.dart`),提供 `saveOutputSnapshot(outputFile)`:复制到 `history/<stem>_<时间戳>.txt`,仅保留最近 20 条。在 `RunPipeline.run()` 写完 ip.txt 后调用。
- **文件**:新建 `lib/core/output/history_store.dart`,`run_pipeline.dart` 调用。

### B2. TCP/可用性结果缓存(对应 Python pickle 缓存)🟡
- **现状**:无缓存,每次全量重测。
- **修法**:新建 `lib/core/cache/result_cache.dart`,用 JSON 持久化 TCP 结果(节点→延迟ms)与可用性结果(节点→栈)。提供 `loadTcp()/saveTcp()/loadAvail()/saveAvail()`,带文件时间戳校验。`AppConfig` 已有相关超时字段;在 `RunPipeline` 增加 `useCache` 参数(由 RunNotifier 暴露,或默认开启读缓存、失败则重测)。注意:这是**加速缓存**非正确性必需,默认行为与 Python 一致(无 `--skip-*` 时重测)。
- **文件**:新建 `lib/core/cache/result_cache.dart`,`run_pipeline.dart`。

### B3. 自动调度 UI(对应 Python `_on_sched_toggle`)🟠
- **现状**:运行页无定时条;`AUTO_SCHEDULE_*` 仅配置未接入定时器。
- **修法**:`RunPage` 运行页底部加「⏰ 自动调度」卡片:Checkbox + 间隔 Spinbox + 状态标签;勾选时启动 `Timer.periodic`(间隔 `AUTO_SCHEDULE_INTERVAL_HOURS` 小时,最小 30 分钟),触发 `runProvider.start()`。状态存 `AppConfig` 并持久化。用 `Timer`(替代 tkinter `after`)。
- **文件**:`lib/features/run/run_page.dart`、`lib/features/run/run_state.dart`(可选加调度状态)。

### B4. 运行页实时仪表盘(对应 Python DashboardPanel)🟠
- **现状**:仅 3 个简单指标卡 + 「规划中」占位图。
- **修法**:新建 `lib/features/widgets/dashboard.dart`:
  - 节点统计卡(总数/已测/通过)
  - 性能卡(最快/均速/最低延迟)
  - 时间卡(当前阶段/已用/预估剩余)
  - 测速实时折线图(`CustomPainter` 绘制,最近 100 个测速点,橙色填充曲线 + 网格线)
- 数据流:`RunState` 增加 `DashboardData{total,checked,passed,maxSpeed,avgSpeed,minLatency,stage,elapsedSec,speedPoints:List<double>}`;在 `RunPipeline` 的测速/TCP/可用性过程中通过 `onProgress` 回调回传数据点(`RunNotifier` 转发到 state)。测速回调在 `speed_prober.dart` 的 `runSpeedPass` 增加 `onPoint` 参数。
- **文件**:新建 `lib/features/widgets/dashboard.dart`;改 `run_page.dart`、`run_state.dart`、`run_pipeline.dart`、`speed_runner.dart`/`speed_prober.dart`(加进度回调)。

### B5. 结果页排序 + 复制选中 🟡
- **现状**:`results_page.dart` 仅复制全部,无排序。
- **修法**:表头点击切换排序(速度/延迟/国家升降序,默认按行号);加「复制选中」按钮(支持行多选)。`ResultNotifier` 增加 `sortCol/sortRev`。
- **文件**:`lib/features/results/results_page.dart`、`result_state.dart`。

### B6. 运行页节点数徽标 🟢
- **现状**:无节点数显示。
- **修法**:`RunPage` 标题行显示数据源节点数(读 `nodes_raw.txt` 或经 `DashboardData.total`)。
- **文件**:`lib/features/run/run_page.dart`。

### B7. CLI 子命令(对应 Python argparse)🟠
- **现状**:纯 GUI,无 CLI。
- **修法**:新建 `lib/cli/cfnb_cli.dart`,用 `dart:io` 的 `stdio` + 简易参数解析实现 `--sub-only/--latency-only/--push-only/--skip-fetch/--skip-tcp/--skip-availability/--skip-bandwidth/--skip-dns/--skip-push/--tcp-only/--fetch-only`。复用 `RunPipeline`/`SubscriptionConverter`/`LatencyFilter`/`GithubPush`。在 `bin/cfnb.dart`(新建)作为桌面端入口,`main.dart` 检测 `argv` 有 `--` 前缀时走 CLI 否则启动 GUI。
- **文件**:新建 `lib/cli/cfnb_cli.dart`、`bin/cfnb.dart`;微调 `lib/main.dart`。
